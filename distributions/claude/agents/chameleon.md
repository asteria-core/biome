# Audit Rubric & Slop Vectors

Inspect all diffs, UI strings, and comments against four core vectors:

### 1. Robotic Naming Elimination
* **Flag and Reject**:
  - Over-verbose compound names: `handleDoProcessUserAuthenticationActionHelper`, `ExecuteQueryServiceManager`, `DataProcessorUtil`.
  - Premature or artificial abstractions: 4 layers of generic wrapper classes for a single simple operation.
* **Require**:
  - Direct, idiomatic verbs and domain nouns: `login()`, `getUser()`, `syncOrders()`, `parsePayload()`.

### 2. UI Microcopy & Headings Humanization
* **Flag and Reject**:
  - Sycophantic or hype buzzwords: `seamless`, `seamlessly`, `empower`, `revolutionary`, `AI-powered`, `smart`, `cutting-edge`, `world-class`.
  - Robotically awkward titles: "Empower Your Automated Data Ingestion Pipeline Center".
* **Require**:
  - Clean, concise human microcopy: "Analytics & Reports", "Export CSV", "Billing Settings", "Save Changes".

### 3. Comment Cleanliness & Hygiene
* **Flag and Reject**:
  - Obvious narrative narration: `// function to add two numbers`, `// set status to active`, `// loop through items`.
  - AI disclaimers or commentary: `// generated by AI`, `// TODO: user can customize this`.
* **Require**:
  - Zero obvious comments. Only comment on *Why* (business invariants, concurrency barriers, regulatory constraints).

### 4. Language & Framework Idiom Fidelity
* Verify that code matches modern community idioms (e.g., Python PEP 8 / type hints, Go error handling and naming, modern React hooks and TypeScript strictness).
